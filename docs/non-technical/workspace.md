# Organising your work

## Projects

A project (say "Watermarking" or "Hydrology") keeps its own sources, matrix, map, review queue and notebook pages. Create one on Home, and switch with the project selector at the top of every page. To move sources in, tick them in the Library. Rename or delete a project from "Project settings" at the foot of its Home page. Deleting a project keeps its sources and pages; they just become unfiled.

## Library

All your sources, with filters for kind and status and a search over titles, tags and the full text of every source. Here you can also download a backup of everything as one file, and restore one.

## Matrix

A literature-review table with one row per source. You can:

- filter by text, kind, project and year;
- show only the columns you need (click a heading to see that column alone);
- click a cell to read it in full, and move between cells with the arrow keys;
- add your own columns and have the AI fill them from each source, with a link to the passage it used. A fill only covers the rows on screen, asks first when there are many, and can be stopped or run for a single cell;
- export what is on screen as CSV or Markdown, and draft a synthesis. The synthesis button works only on ticked rows: it asks you to tick 2 to 40 sources and shows how many it will use ("Draft a synthesis from 5").

## Notebook

Pages built from blocks: headings, lists, checklists, toggles, callouts, tables, quotes, code and math. Type `/` for the block menu, `# ` for a heading, `- ` for a list, or `---` for a divider, and type `@` to cite a source. Each page has an icon, an outline, a project and an optional folder. In the sidebar, drag a page onto a folder to file it there, or onto a project's name to move it to that project. The **+** beside a project's name starts a page in it, and folders fold and unfold by clicking them.

A page carries the sources you are working with. Tick sources in the Library and choose "Work with these in the Notebook", then ask questions across them. Answers are written into the page with citations that open the cited passage.

## Map

One concept map across everything you have studied. Squares are sources, circles are concepts, and diamonds are notebook pages. It has the same filters as the Matrix, a "shared concepts only" view for large libraries, and a layout by topic or by year. The topic layout is live: drag a concept and its neighbours follow, and the map settles when you let go. Link wording appears only when you hover or pick a concept. Clicking a concept shows what it means and which sources use it.

## Search everything

`Ctrl K` (or `/`) opens one box that finds any source, note or page, searches the full text, or adds a link you paste.

Reloading the page brings you back to the screen you were on, including the source and tab you had open.
